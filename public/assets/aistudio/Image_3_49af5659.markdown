## Brand & Style

This design system serves an academic usability evaluation environment, dedicated to analyzing System Usability Scale (SUS) benchmarks and After-Scenario Questionnaire (ASQ) metrics. The design language marries the focused, keyboard-friendly efficiency of modern developer tooling (Linear-inspired) with the calm precision demanded by rigorous empirical research.

### Aesthetic Persona & Ethos
- **Minimalist & Scholarly:** No arbitrary gradients, theatrical illustrations, or visual bloat. The user interface prioritizes clarity, data density, and signal-to-noise ratio.
- **Calm Analytical Focus:** A slate-infused neutral palette reduces cognitive strain across long-form analysis of psychometric Likert-scale responses, percentile distributions, and scenario-based completion curves.
- **Precision Engineering:** Monoline metric dividers, micro-status tags, tight tabular alignment, and deliberate typographic rhythm evoke scientific credibility.

### Target Audience
HCI (Human-Computer Interaction) researchers, academic research faculties, usability specialists, and UX analysts operating in both institutional research and industrial lab environments.

### Localization & Tone
All operational interface labels, states, metrics, and prompts use standardized, formal academic Bahasa Indonesia (e.g., *Skor SUS Komposit*, *Tingkat Keberhasilan Skenario*, *Deviasi Standar*, *Metrik Responden*).

## Colors

The palette employs a restrained, academic color system calibrated for high readability and minimum optical vibration during prolonged statistical review.

### Palette Architecture
- **Primary (`#547A9E`):** Muted Academic Slate Blue. Serves as the primary operational anchor for key active states, benchmark indicator bars, targeted interactive triggers, and focused navigation nodes.
- **Primary Light (`#EAF1F7`):** Tinted Soft Azure. Deployed for subtle state highlights, hover accents on tables/nav links, and container backings for key metric badges.
- **Canvas / Background (`#F8FAFC`):** Pristine slate-gray canvas that defines the workspace periphery.
- **Surface (`#FFFFFF`):** High-clarity white utilized across metric cards, analytical data tables, calculation canvases, and contextual modals.
- **Main Text (`#263445`):** Deep Slate Ink for all structural headlines, scalar values, and body text, ensuring WCAG AAA accessibility.
- **Secondary Text (`#84909E`):** Neutral Slate Muted for microcopy, data field metadata, question IDs (e.g., `Q1–Q10`), and auxiliary metrics.
- **Structural Border (`#E7EBF0`):** Ultra-refined structural line color for data grid borders, dividing rules, and card strokes.
- **Functional Semantics:**
  - **Success / Acceptable (`#6F9C85`):** Muted Sage Green. Signifies SUS scores above empirical benchmarks (e.g., Grade A/B, SUS > 68), positive ASQ completion ratings, and statistical significance.
  - **Warning / Marginal (`#D5AA68`):** Ochre Sand. Denotes marginal usability thresholds (SUS 51–67.9), elevated scenario task friction, or low participant sample sizes.
  - **Critical / Reject (`#C86A61`):** Subdued Terracotta. Reserved strictly for critical evaluation anomalies, usability failure boundaries (SUS < 50), and invalid survey submissions.

## Typography

Typographic hierarchy in this design system leverages **Inter** for its neutral structure, exceptional x-height, and superior tabular rendering across dense academic datasets.

### Typographic Principles
- **Tabular Figures (`tnum`):** Numeric values (SUS composite scores, ASQ 1–7 ratings, confidence intervals, sample sizes) must always render with OpenType tabular figures to ensure column alignment in research spreadsheets and statistical card tables.
- **Restrained Scaling:** Headings avoid dramatic consumer-oriented scale. Hierarchy is achieved using subtle variations in weight (`500` vs `600`) and slight adjustments to tracking rather than oversized display fonts.
- **Academic Labeling:** All metadata tags and category indicators employ `label-sm` with slight uppercase tracking (`+0.04em`) to establish visual separation without clutter.

## Layout & Spacing

The dashboard operates on a strict desktop-first layout with an 8px base grid rhythm, balancing dense information with calm whitespace.

### Structural Architecture
- **Fixed Compact Sidebar:** 
  - Standard width: `240px` (collapsible to an icon rail of `64px`).
  - Anchors global navigation: *Ringkasan Evaluasi* (Overview), *Studi SUS* (SUS Studies), *Evaluasi ASQ* (ASQ Evaluations), *Basis Responden* (Respondent Pool), and *Laporan Akademik* (Reports).
- **Primary Content Stage:** 
  - Desktop-first fluid stage with a minimum screen width constraint of `1280px` and optimal rendering up to `1920px`.
  - Max container restriction: `1600px`, centered on ultra-wide displays.
  - Consistent canvas padding of `1.5rem` (`24px`).
- **Data Card Rhythm:**
  - Metric summary strips utilize a 4-column layout with `1rem` (`16px`) gutters.
  - Split views (e.g., individual item score breakdown alongside psychometric distribution curves) rely on a 7:5 ratio grid.
- **Component Padding Scale:**
  - Micro tags/chips: `space-xs` vertical, `space-sm` horizontal.
  - Form inputs, table cells, and button primitives: `space-sm` vertical, `space-md` horizontal.
  - Analytics card interiors: `space-lg` (`20px`) all sides.

## Elevation & Depth

This design system adopts a flat, tactile philosophy that rejects deep drop shadows in favor of low-contrast outlines, tonal containment, and whisper-quiet ambient elevation.

### Hierarchy Tiers
- **Tier 0 (Canvas Base):** Surface color `#F8FAFC`. Zero elevation, pure plane.
- **Tier 1 (Surface Containers & Cards):** Flat `#FFFFFF` fill bounded by a crisp `1px` solid border (`#E7EBF0`). Zero box-shadow under static conditions.
- **Tier 2 (Interactive Hover & Context Menus):** A whisper ambient shadow:
  `box-shadow: 0px 2px 4px rgba(38, 52, 69, 0.04), 0px 1px 2px rgba(38, 52, 69, 0.02);`
  accompanied by a border transition to `#D1D9E2`.
- **Tier 3 (Floating Popovers, Modal Dialogs & Tooltips):** 
  `box-shadow: 0px 8px 16px -2px rgba(38, 52, 69, 0.06), 0px 4px 8px -2px rgba(38, 52, 69, 0.04);`
  Enclosed with `1px solid #E7EBF0`.

Glassmorphic overlays and saturated blurs are strictly avoided. Depth is expressed purely through structural separation, thin lines, and clear tonal zoning.

## Shapes

The interface balances sharp analytical precision with subtle softness using an 8px (`0.5rem`) geometric baseline.

### Corner Radius System
- **Metric Cards, Data Tables & Containers (`rounded-md` / 8px):** Structural panels use 8px corner radii to maintain a clean grid alignment.
- **Inputs, Filter Selectors & Buttons (`rounded-md` / 6px - 8px):** Consistent interactive primitives that match analytical card architecture.
- **Badges, Status Chips, & Likert Node Badges (`rounded-sm` / 4px or `rounded-full` / 9999px):**
  - Informational tags (e.g., percentile grade badges `Grade A-`, `P75`) use `4px` corners.
  - Micro state-dots and avatar initials use full circles (`rounded-full`).
- **Dividers & Structural Rules:** Absolute `1px` clean borders with square terminations.
